# ユーザーメニューとnote活用術（0.1.3開発）

ひきこもりnote 0.3.4開発版の実装を参照し、おしゃべりnoteの固定モードに合わせて移植する。新規設定・権限・通信・タイマー・Observer・保存形式は追加しない。移植元と0.1.2タグ・提出物を変更しない。コミット・push・タグ・公開は行わない。

## ユーザーメニュー

- ポイント残高・チャージ枠は `hidePaidArticles`、noteプレミアムサービス・note活用術の入口は `hideArticleRecommendations` に連動する。
- 既知の `min-w-[262px] py-6 md:py-0` 枠内のアバター、note.comのアカウント設定とログアウトリンクで公式メニューを確認する。本文・拡張所有DOM・未知構造は対象外。
- ポイント履歴と「チャージ」の2リンク、所持noteポイントのSVGがある既知行を隠す。それだけの区画なら区画を隠し、別の機能があれば既知行だけを隠す。
- プレミアムの専用ボタンは既知LIを対象とする。「note活用術」とヘルプが並ぶ既知行では、活用術と区切りのスラッシュだけを隠す。
- 購入履歴・参加サービス・マガジン・スキした履歴・最近みた・ヘルプ・ログアウトなど他機能は維持する。リンク先は認証情報のない公式originとpathnameで確認する。
- 遅延挿入・DOM交換は既存変更通知、設定変更は既存同期で更新する。変化のない定期同期では再走査しない。設定OFF・拡張OFF・停止・対象DOM撤去で非表示属性を解除する。

## note活用術

- `https://note.com/help` と `/help/pg/` 配下のページを `help` 種別として認識する。`/help/pg/` だけの未確定URL、未知のhelp下位、外部help-note.comを対象にしない。helpをクリエイターIDとして扱わない。
- 既存の共通左メニュー・狭幅ハンバーガー・ヘッダ固定・歯車からお気に入りへの導線を再利用する。通常は4グループ、2段は8グループ。おしゃべりnoteに存在しない重度・社会復帰モードの設定は新設しない。
- 本文や活用術ページ内タブは維持する。幅変更、SPA、OFF、停止時の復元を既存処理で扱う。

## 記事お気に入りフォームの配色

0.1.2のselect／option配色修正を維持し、記事用フォームのlabel・p・button・select・optionにnoteの文字色を明示する。背景は既存の通常サーフェス、変数なしではCanvas／CanvasText。広幅とハンバーガーは同じフォームを使い、登録・開閉・保存処理は変更しない。

## 検証

メニューの各設定組合せ、他機能の維持、後挿入・交換・範囲外除外・再走査抑制・OFF／停止を検証する。helpのURL境界、4／8グループ、幅変更・SPA・本文保持・歯車遷移を確認する。実際のログイン済みnoteメニューと各ブラウザのネイティブ表示は別途実機確認事項とする。

### 実施結果（2026-11-16）

- 構文検証・自動テスト576件成功（既存570件＋今回6件）。既存の歯車遷移試験にもhelp／外部ヘルプ／未知パスを追加した。
- 隔離Chromeのローカル匿名DOMで、実際のCSSとUI処理を適用し、ポイント・プレミアム・活用術・区切りの非表示、ヘルプ・購入履歴・ログアウト・本文の維持、8グループの狭幅メニュー、OFF・停止での復元を確認した。実際のnoteへのログインや外部通信は行っていない。
- Chromium／Firefoxの0.1.3開発版を生成・照合した。0.1.2の配布物とタグは保持する。実noteとFirefox／Edgeでの実操作、Chromeのネイティブ選択肢描画は未確認。
