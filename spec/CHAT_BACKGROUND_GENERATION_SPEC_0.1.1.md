# 画面切り替え時の生成継続（0.1.1）

「通常の会話」「タグの提案」「記事について」の切り替え、お気に入り・設定など左メニューへの移動では、実行中のLLM通信を中止しない。回答は送信時の会話ID・epoch・生成IDに関連付けて保存し、別の会話の表示や下書きへ混入させない。

生成は従来どおり全画面で同時に1件。別の会話を表示していても二重送信しない。記事の待機キューも、接続済みホームが開いていればメニューや上部タブの選択にかかわらず継続する。画面選択を戻したり、別タブをアクティブにしたりしない。

明示的な中止は、表示中の会話にかかわらず実行中の生成と待機キューを取り消す。新しい会話は選択中だけ初期化し、その会話が生成中なら中止する。他の会話の生成は継続する。設定変更・権限取消・接続切断・画面の再読込やブラウザタブの終了による停止は維持する。

ホームのUI処理を通信の所有者として維持する方式であり、すべてのホームを閉じても生成を続ける仕組みは追加しない。
