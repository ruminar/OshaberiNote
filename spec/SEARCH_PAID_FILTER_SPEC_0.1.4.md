# 検索の記事絞り込みの非表示（0.1.4）

2026-11-18。ひきこもりnote develop f918423上の未コミット修正を読み取り専用で参照する。

拡張ONかつ「有料記事を非表示」の検索画面では、「すべての記事／有料の記事」を選ぶコンボボックスを裏側selectと専用枠ごと隠す。有料の検索結果が非表示になって空いた領域を公式の無限スクロールが埋め続ける操作への入口をなくす。

main#main-content内のdiv.w-36.shrink-0 > div[data-name="Field"]、FieldButtonのaria-label「記事の絞り込み」、option値note/note_for_sale、同じ行の並び順を確認する。本文と拡張所有DOM、未知の選択欄を除外する。初期非表示用の文書ルート属性と子孫CSSも移植し、遅延挿入時の一瞬の表示を抑える。

設定解除・拡張OFF・検索画面からの離脱・停止・DOM差し替えで属性を解除する。並び順・関連トグル・検索結果・URLと既存の4/8やチャットは変更しない。既に有料検索URLを開いた場合の条件解除・転送は対象外。新しい通信・権限・設定・タイマー・Observerは追加しない。

移植元や公開済みタグ・提出物は変更せず、コミット・push・タグ・公開は行わない。

## 確認結果

構文検証・全660件の自動試験成功（今回2件追加）。専用枠と裏側select、対象限定、設定解除・OFF・離脱・停止の復元、遅延挿入・DOM再描画を確認した。隔離Chromeの匿名ローカルDOMでも実CSSによる非表示・設定解除／停止時の復元と既存表示の維持を確認した。実note上とFirefox／Edgeの実機表示・操作は未確認。
