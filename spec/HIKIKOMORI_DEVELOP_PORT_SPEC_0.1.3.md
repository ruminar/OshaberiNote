# ひきこもりnote 0.3.4 develop追加対応の移植

2026-11-17。移植元は `HikikomoriNote/develop` の `a38b0ee`。対象はおしゃべりnote 0.1.3の作業ツリーのみ。移植元・0.1.2タグ・提出物を変更せず、コミット・push・公開は行わない。

## 調査と選定

既存のユーザーメニュー連動、helpの共通メニュー、記事フォーム配色、お気に入り整理画面と共通宛先・スクロール保持・左側への成功通知抑制は移植済みとして保持する。追加対象は作者検索の＠登録、新タグカードの価格判定、新チップ枠、設定画面と共通左メニューのドラッグ操作。Shift試作ブランチとAndroid専用ブランチは対象外。モード選択・JSON形式・LLM機能を移植元で上書きしない。

## 作者検索からの登録

- URLで確認できるfrom:@作者検索にのみ、TLリンク直前の＠ボタンを追加する。現在選択中グループに未登録の場合だけ表示。表示名は既存作者カード情報、IDは検索URLから取得する。
- 直接追加して成功後にボタンを消す。別グループでは未登録なら再表示。登録先4／8、重複判定、保存中・失敗・結果未確認・再確認は既存処理を使う。
- noteメインフレームの現在URL・遷移中URL・検索作者ID・選択ID／リビジョンを背景処理で検証し、保存直前にも再確認する。一般の作者追加権限は広げない。

## DOM変更への対応

- タグ／hashtag一覧でも既知のrelative/w-fullと[grid-row:2]を持つ新カードを有料記事判定に含める。既存価格・鍵・条件付き無料、作者許可、本文除外、OFF復元を再利用し、未知URL・未知構造へ広げない。
- 記事末尾の既知チップsectionは、従来の直下ボタンに加え、ボタン1個だけのdivを1段挟む構造を許可する。本文内・深い未知構造・別のボタンは対象外。余白枠の除去と復元は既存処理を使う。

## グループ番号へのドロップと並べ替え

- 設定のお気に入り一覧、お気に入りグループを持つ共通左メニュー（following／tag／hashtag／search／topic／help）へ適用する。広幅・ハンバーガーの既存4／8グループを使い、専用ナビへ新しいグループ欄を追加しない。
- 同じ画面内で開始した項目ドラッグのみ許可する。別番号へドロップすると末尾へ移動、現在番号へドロップするとお気に入りから削除する。ドラッグ中だけ現在番号を赤いゴミ箱に変え、title／aria-labelで削除を明示する。記事本体等を削除する操作ではない。
- 5種類の項目、全グループ横断の記事重複防止、非表示グループ制限を維持する。移動先重複は元項目を維持して拒否する。番号クリックは通常の選択切替を維持し、ドラッグ中のホバーだけでは切り替えない。
- 項目上半分／下半分・一覧末尾で並べ替え、左メニューでは挿入線を表示する。同順序や自身への並べ替えは無操作とする。既存の上下・削除・共通宛先移動ボタンは維持する。
- 外部データ・別画面ドラッグは拒否する。設定・選択・ページ・配置変更、メニュー閉鎖・画面切替・停止で中断する。左メニューの変化のない定期同期はドラッグを維持する。
- note側へ許可するメッセージは限定したmenu-favorite-dropのみとし、REMOVE_TAG／TRANSFER_TAG／MOVE_TAGだけを扱う。操作元はドラッグ開始時のURLを使い、現在タブ・遷移中・選択リビジョン・保存直前のページを検証する。一般のtag-operationをnoteへ開放しない。
- 新しい設定・権限・通信・監視・タイマー・保存形式は追加しない。既存の保存キュー・競合・失敗／結果未確認・スクロール・フォーカス保持を再利用する。タッチドラッグは保証せず、既存ボタン操作を残す。

## 検証

移植元の回帰試験をおしゃべりnoteの固定モードと表示設定へ適合させて実施する。作者検索登録、URL／送信元境界、カードとチップの誤判定防止、5種×4／8×広幅／狭幅、重複、キャンセル・外部データ・保存失敗・競合・既存操作を検証する。実機確認は自動DOM試験と区別して報告する。

- 共通メニュー13種類のURL×広幅／狭幅×4／8グループ、全5種類の項目、項目間・末尾への並べ替え、移動・削除、外部データ拒否、選択変更・ページ変更・保存直前の競合、保存失敗・結果未確認・再確認を検証した。一般のtag-operationをnoteへ開放していないこと、ブラウザAPIの現在タブ・pendingUrl照合も検証した。

- 移植元のファイル・ブランチは変更せず、おしゃべりnoteへのコミット・push・公開も行わない。
