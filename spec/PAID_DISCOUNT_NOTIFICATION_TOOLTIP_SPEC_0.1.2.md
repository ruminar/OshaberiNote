# 条件付き無料記事と通知ツールチップ（0.1.2）

## 有料記事非表示

- ひきこもりnoteの対応を移植する。既存の有料価格・メンバーシップ判定に加え、価格欄が「¥0〜」かつ同じ価格行の直接の子に「割引あり」バッジがある記事を対象とする。
- 価格spanと親divの `text-text-success`、価格行divの `flex items-center gap-2`、バッジspanの `bg-surface-offer rounded-full` を確認する。範囲記号は `〜`・`～`・`~` に対応する。
- 通常の0円表示、価格なし、別行の割引表示、本文中の記述だけでは新たに非表示にしない。表示許可作者、購入済み一覧の除外、設定OFF・拡張OFF・停止時の復元は従来どおり。
- 遅延挿入と価格変更は既存のDOM変更通知で再評価する。マガジン価格判定は変更しない。

## 通知の作者アイコン

- 公式通知欄 `#notifications` のli内にあるプロフィールリンク配下の `button[data-name="avatar"]` に標準titleを設定する。画像altを表示名、同じリンクのnote.com公開プロフィールURLをユーザーIDの根拠にする。複数作者は個別に扱う。
- 通常・表示許可作者は `　表示名（@ユーザーID）`、非表示設定作者は `　！表示名（@ユーザーID）`。どちらも先頭1文字は全角スペース（U+3000）。表示名が取得できなければIDで代替する。
- 通知外、拡張所有DOM、外部URL、記事URL、識別できない構造は変更しない。通知を非表示にせず、クリック・フォーカス動作も変更しない。
- 遅延挿入・href/alt変更は既存Observerの通知で、作者設定変更は既存同期で反映する。変更のない定期同期では再走査しない。
- OFF・通知DOM撤去・停止時は元のtitle（なければ属性なし）へ戻す。公式側がtitleを書き換えていた場合は、その値を壊さない。
- 新設定・権限・通信・タイマー・Observer・ストレージ項目は追加しない。ユーザーIDは表示用にDOMから読み、保存しない。

## 検証

- 条件付き無料、通常0円、誤判定防止、遅延変更、許可作者、購入済み、OFF・停止を回帰テストする。
- 通知の複数作者、設定変更、遅延挿入、alt/href変更、範囲外除外、元titleの復元と公式更新の保護を検証する。
- 実際のnote通知欄とブラウザ標準ツールチップの描画は実機確認事項とする。
