# おしゃべりnote 0.1.6 お気に入りとアカウントメニュー

ひきこもりnote 0.3.7の実装（`9d9aa95`、`f0ea67f`）を移植する。

## お気に入りグループの一括削除

- 専用ホームの「お気に入り」で、移動先の右に「①の項目を全削除」を置く。番号は選択中のグループに追従し、空のグループや保存中は無効にする。
- 確認画面にグループ番号・名前・件数を表示する。承認後にそのグループの項目をすべて削除し、グループ名、選択、他グループは維持する。
- 確認から保存までにグループの内容または選択が変わっていれば削除しない。設定画面の既存の保存キューとリビジョンを利用する。

## ダッシュボード非表示時の本人検索

- 拡張ONかつ「ダッシュボードを無効化する」が有効なとき、note公式アカウントメニューの設定ボタンの左に「＠表示名」を表示する。
- 同じアカウントメニューのプロフィールリンクから本人のIDを取得し、既存の作者検索URLで、その本人の記事を新着順に表示する。表示名が取れなければIDを表示する。
- アカウントメニューの差し替えに追従し、拡張OFF・設定解除・停止時には追加リンクを取り除く。
