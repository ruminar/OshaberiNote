# タグ登録ダイアログの8グループ配置（0.1.4）

タグ提案等のAI回答から開くタグ操作ダイアログで、通常の4グループは従来の縦1列、2段設定の8グループは2列×4行にする。順序は①②／③④／⑤⑥／⑦⑧。検索と閉じるボタンはグループ配置に含めない。

既存の操作可能グループからボタンを構築し、その個数をグループ領域のdata-group-countへ設定する。8個のときだけCSS Gridを適用する。表示設定を開いたダイアログへ反映する際も配置を更新する。長い名前・登録済み表示は折り返し、狭幅でも横にはみ出さない。ダイアログ既存の高さ上限とスクロールは維持する。

保存・登録済み判定・重複防止・検索タブ・JSON形式は変更しない。0.1.3タグと提出物を保持し、0.1.4の未コミット開発変更として残す。コミット・公開は行わない。
