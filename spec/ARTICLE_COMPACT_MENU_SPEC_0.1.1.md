# 狭幅の記事操作メニュー（0.1.1）

記事ページで左側の固定操作欄を表示できない場合、既存のヘッダのnoteロゴ横にハンバーガーボタンを追加する。広い画面の固定操作欄は従来どおりとする。

開いたメニューは、フォロー中のTLを1行、その下に作者ページ／＠作者、前の記事／次の記事、この記事を要約／記事全文を取得を2列で配置する。操作結果の通知は全幅で表示する。既存のリンク・作者照合・前後記事取得・要約キュー・クリップボード処理を再利用し、ボタン表示だけで取り込みやLLM送信を行わない。

開閉はaria-expanded・aria-controlsを付け、Escapeで閉じてボタンへフォーカスを戻す。移動用リンクの選択・記事URL変更時にも閉じる。要約・コピー操作では結果を読めるように開いたままとする。狭幅と広幅の切り替えでは同じ操作要素を移し、二重表示やイベントの重複を防ぐ。拡張OFF・記事以外への移動・停止時は追加した表示を撤去する。

確認済みの公式ヘッダ・ロゴと表示中の記事が見つからない場合は追加しない。非公開部分や未読込iframeの強制取得など、本文取得仕様は変更しない。
