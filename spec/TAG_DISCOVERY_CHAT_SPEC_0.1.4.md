# タグ一括登録のチャット入口（0.1.4）

2026-11-18。ひきこもりnote spec/tag-discovery-bulk-registration.mdを全文確認し、既存実装を調査した。実ファイルは.specではなくspec配下。おしゃべりnoteの入口①タグ登録支援・②記事タグ確認、共通extract/createDialog、bulkAddTags/ADD_TAGSは実装済み。残る入口③を追加する。

## 実装方針・範囲

- src/chat-ui.jsで、完了したAI回答のコピー左に「まとめて確認」を置く。通常の会話・タグの提案・記事について共通の回答描画へ接続する。生成中・中断回答とユーザー発言には追加しない。
- クリックした回答1件の原文だけを共通extractへ渡す。別回答・質問・履歴は含めない。タグなし・入力制限等は回答行へ通知する。押すだけでは保存しない。
- src/home.jsで既に保持するcreateDialogの同じ実体を利用する。ダイアログや保存ロジックをチャット側に増やさない。ホームの登録入口APIから既存bulkAddTagsへ渡し、保存結果は既存show/subscribeでお気に入り管理とチャット双方へ反映する。既存の単一タグダイアログは検索・個別登録用として維持する。
- 候補は初期全OFF、全ON/OFF、件数、登録先4/8、重複・容量・保存キュー・保存結果不明の再確認は既存共通処理を使う。会話切替・初期化・画面離脱でチャット由来ダイアログを閉じる。元回答の有効性を操作時と保存時に確認する。
- 両拡張は独立したstorage.localを利用する。おしゃべりnote自身の保存先へ登録し、ひきこもりnoteへ自動反映しない。既存設定JSONで移行する。ひきこもりnoteには入口①②が実装済みで、今回の別リポジトリ修正は不要。
- JSON・権限・ネットワーク・LLMプロンプト・履歴・リリース方式は変更しない。おしゃべりnoteは従来どおりPC向けでありAndroid対応を追加しない。コミット・push・タグ・公開は行わない。

## ひきこもりnote 0.3.6からの追補

- note上の個別登録と共通のタグ一括登録、おしゃべりの個別タグ登録では、CtrlまたはShiftを押しながら登録するとグループの先頭へ追加する。通常操作は末尾へ追加する。一括登録時は新規タグの表示順を保つ。
- note上の左メニューとハンバーガーメニューのお気に入り一覧は、グループの切り替えや検索による再描画でグループごとのスクロール位置を復元する。同じブラウザタブ内のページ移動にも引き継ぐ。初回表示やグループ切り替え時に、現在表示しているページへのリンクが見切れる場合だけ一覧を調整する。

## 0.1.6 ユーザーIDの取り込み

- 専用ホームの「タグ登録支援」で、タグに混ぜて `[@ユーザーID]` を貼り付けられる。角括弧で囲んだ形式の有効なIDだけを候補にする。記事タグ、チャットの「まとめて確認」、コピー用プロンプトはタグを扱う。
- 同じ一覧で候補を選び、入力順で一括登録する。通常クリックは末尾、CtrlまたはShiftを押した登録は先頭に追加する。既存の作者項目形式を使い、同じグループのIDの大小文字違いは重複とする。
- 作者検索の公式結果に同じIDの表示名が出たとき、表示中のグループにある該当項目の空欄だけを補完する。追加の外部通信は発生しない。
