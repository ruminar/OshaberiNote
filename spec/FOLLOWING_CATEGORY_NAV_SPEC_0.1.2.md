# 0.1.2 フォロー中TLの公式カテゴリナビ非表示

ひきこもりnoteの対応済み処理を参考に、拡張ONの/followingでは、すべて・フォロー中・急上昇・注目・投稿企画・タグ等の横並び公式カテゴリナビを外枠ごと非表示にする。新しい設定は追加しない。

既存のレイアウト準備処理で確認済みのグリッドへ、/following専用の印を付ける。その直下のlg:hidden・w-fullを持つdivで、直下にnav[aria-label="カテゴリナビゲーション"]かつoverflow-x-autoの横スクロール領域を持つ場合だけCSSで隠す。本文・未知の構造・公式ヘッダ・拡張のハンバーガーとお気に入り・検索対象タブは隠さない。

既存のDOM変更通知・同期・幅変更処理を使い、後挿入にもCSSで適用する。追加のタイマー・Observer・通信・権限・保存形式の変更は行わない。/following以外へのSPA遷移、OFF、レイアウトの切断・境界不一致、停止で印を解除する。ひきこもりnote側は変更しない。コミット・公開・リリースは行わない。

既存のカテゴリ表示切り替えはおしゃべりnoteの固定モード内だけに適用する。記事お気に入り、歯車の遷移先、LLM機能の既存変更は保持する。確認対象は/following限定、後挿入・幅変更・SPA・OFF・停止・レイアウト差し替えと、記事一覧や検索タブへの非影響。
