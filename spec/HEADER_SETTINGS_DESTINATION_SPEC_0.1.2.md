# 0.1.2 歯車リンクの遷移先

note公式ページのロゴ横に拡張が追加する歯車は、現在のページに応じた専用ホーム内の画面を開く。

- ユーザーのクリエイターページ：ユーザーの表示管理（home.html#authors）。
- お気に入り機能を利用するモードの公開記事・フォロー中のTL・タグ・検索・話題・マガジン・メンバーシップ（参加画面を含む）：お気に入り（home.html#tags）。
- プレビュー・質問箱・管理画面・判定不能など、上記以外：設定（home.html#settings）。

ひきこもりnote 0.3.2のページ別分岐を参考にし、歯車専用の遷移先関数として分離する。noteロゴ、ホーム転送、拡張アイコンの「おしゃべり」への遷移は変更しない。SPA移動後は既存同期で同じ歯車のhrefを更新し、通常・修飾クリックや別タブで開くブラウザ標準動作は維持する。新設定・権限・保存形式・通信は追加しない。

本書はOshaberiNote_SPEC_0.1.0.mdの「歯車は設定へ」という規定を、0.1.2について置き換える。今回は開発中の修正のみで、コミット・公開・リリースは行わない。
