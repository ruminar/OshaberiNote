# Firefox 試作の読み込み

PC版Firefox 140以上で、既存のひきこもりnoteを無効にしてください。`about:debugging#/runtime/this-firefox` →「一時的なアドオンを読み込む」から、このフォルダの `manifest.json` を指定します。Androidは対象外です。

Ollamaを起動し、拡張アイコン →「LLMの設定」→「接続・再試行」→ 接続権限と会話送信の任意同意（personalCommunications）の許可 → モデル選択 →「おしゃべり」→ 送信の順で確認します。拒否しても既存のnote機能は利用できます。「LLMの設定」で接続先を変更すると会話・モデル選択・システムプロンプトを初期化します。

必要な場合はOllamaの `OLLAMA_ORIGINS` にこの専用ホームの実際の `moz-extension://実行時UUID` を追加して再起動します。アドオンIDと実行時UUIDは異なります。全サイト・全拡張を許可しないでください。

ローカル専用運用ではOllama側で `OLLAMA_NO_CLOUD=1` を設定して再起動してください。HTTPのLAN通信は暗号化されません。この試作は署名・公開していません。

専用ホームはOS・ブラウザの配色設定に追従します。チャットはCtrl+Enterで送信、Enterで改行します。IME変換中は送信しません。

通常チャット用のシステムプロンプトも「LLMの設定」で保存できます。変更の保存時は通常タブの会話だけを初期化し、空欄で保存すると追加のプロンプトを解除します。

入力は最大200,000文字です。履歴は各会話タブで直近10往復・最大2MiBを保持し、古い分から自動整理するため、履歴量で会話を打ち切りません。長文はOllama側でも切り捨てられる場合があります。

「おしゃべり」上部の「通常の会話」「タグの提案」をタブとして切り替えます。初期表示は通常タブで、各タブの履歴を別々に保存・復元します。タグタブの初回選択時だけ最初の質問を作り、接続・モデル選択済みなら送信します。未接続なら入力欄で待ち、再選択では再送しません。専用プロンプトv1.2と全4グループの最新登録タグ名はタグタブの送信だけに付与します。「新しい会話」は選択中のタブだけ初期化します。提案タグの登録は利用者の操作時だけ行います。
