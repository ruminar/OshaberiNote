# おしゃべりnote 0.1.0

noteのホームを、Ollamaと話せる専用ホームに置き換える非公式拡張の初回リリースです。

## 主な機能

- 「通常の会話」「タグの提案」「記事について」を履歴の分かれたタブで利用できます。
- タグの提案には最新のお気に入りタグを反映し、回答中のタグからnote検索や4グループへの登録を行えます。
- 記事ページからタイトル・著者・本文を取り込み、要約・感想・修正点・引用の列挙を依頼できます。自由入力では同じ記事の会話区間だけを使います。
- 本文リンク、添付ファイルのURL、リンクカードの情報を取り込み、過去の発言の記事タイトルから元記事も別タブで開けます。
- 記事本文・会話はブラウザ終了後も保持し、「新しい会話」で選択中のタブを初期化できます。
- システム・ダーク・ライトのテーマ、Ctrl+Enter送信、メッセージコピー、発言単位の移動、太字・箇条書き・URLリンク表示に対応します。
- お気に入り、作者の表示管理、閲覧設定、設定JSONの移行に対応します。

## 導入

Chrome・Edgeは `OshaberiNote-0.1.0-chromium.zip`、PC版Firefox 140以上は `OshaberiNote-0.1.0-firefox.zip` を展開し、同梱の `INSTALL.md` に従って読み込んでください。Ollama本体とモデルの用意が別途必要です。

ブラウザストアには登録していません。Firefox版は未署名で、一時的なアドオンとしての手動読み込み用です。Androidは対象外です。ひきこもりnoteとの同時有効化は避けてください。

## 検証と制限

- 自動テスト470件成功。配布ZIPと展開先・ソースの一致を検証しています。SHA-256は `SHA256SUMS.txt` に記載します。
- Chrome・Edgeの一時プロファイルで主要機能を確認しています。Firefoxの実ブラウザ操作、実容量上限、保存途中のプロセス強制終了からの復旧は未確認です。
- ローカルgemma3:12bで記事の参照URL9件の列挙を確認しました。AIの説明・引用判定・著者情報などの正確性を保証するものではありません。
- 未読み込みカードのタイトル・著者は未取得として扱います。リンク先の記事本文や添付ファイル本体は取得しません。
- 通常会話・タグ提案は直近10往復・各2MiB、記事会話は往復数制限なし・履歴2MiB・本文を含む全体8MiBまで保持します。記事はモデルのコンテキストに収まらなければエラーになり、自動再送しません。
- 会話・記事は暗号化せずブラウザに保存します。クラウドモデルではOllama側から外部へ通信します。
- 設定JSONの寛容な形式判定や、ひきこもりnote側の連携改修、複数記事をまとめる連作機能は含みません。

詳細はREADME、PRIVACY.md、docs/manual-test.mdを参照してください。note株式会社・Ollamaとは関係ありません。
