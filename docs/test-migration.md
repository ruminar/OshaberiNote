# 流用試験の置き換え

元製品専用の3モード切替・旧JSON形式での書き出し・欠落項目を解除する全置換の試験は、本製品の `transfer.test.cjs` と `chat.test.cjs` の固定モード・部分移行・安全性の試験へ置き換えました。通常動作の表示・お気に入り・作者管理の回帰試験を維持します。

置き換えた元試験：

- 社会復帰ではホームのロード・クリック・SPAを奪わず、ダッシュボード制限だけ継続
- 社会復帰の歯車は設定へ、プロフィールでは既存の作者管理へ向かう
- モード変更とタグ操作は同じキュー。先の保存を保持し後のタグ操作を拒否
- 左メニューでタグ管理と設定を切替。重度では設定入口とキャッチコピーだけにする
- 重度の初期表示はキャッチコピーだけ。設定から解除しタグ一覧を保持する
- 専用ホームの左メニューで設定を開き、#settingsは重度でも設定を直接表示する
- 設定JSONは全設定と4グループを往復し、内部番号・診断・未対応項目を持ち込まない
- 社会復帰の保存はホームDNRだけ除去し、再起動・OFF・通常復帰でも設定とタグを保持
- 社会復帰ではタグ編集を背景処理でも拒否し、通常に戻せば保存データで再開
- 社会復帰の設定画面はタグへ入れず、未保存モードは動作を変えず保存後だけ切替
- 設定メニューは設定を先頭に並べ、タグ直行は#tagsだけ。社会復帰と重度はタグを開かない
- 社会復帰の有料非表示ONだけホームのおすすめメンバーシップをCSSで先行非表示にする
- ホームのおすすめメンバーシップは作者許可・自己設定・記事おすすめ設定から独立して行単位で隠す
- 設定形式7はヘッダ設定を往復し、旧形式1～3はOFF。不正な型や欠落は保存しない
- 形式7は種類付き項目を順序通り往復し、旧形式4の明示読込と破損データ保持も維持
- 旧JSONでお気に入りユーザーが解除されることを確認し、キャンセルなら保存しない
- 形式7で3種類を順序通り往復し、不正マガジンは全置換前に全体を拒否する
- 旧JSON全置換はマガジンの解除も確認し、キャンセルでは現在の設定を保持する
- 形式7で4種類を往復し、形式5は従来3種類だけ受理。不正データは全体を保存前に拒否
- 重度モードの共通左メニューは設定済みの自分のページ1件だけ。お気に入りとTLは出さない
- 重度でも先行非表示・公式DOM交換に対応し、未知構造と対象外では推測で隠さない
- 設定形式7は作者名・状態を往復し、形式1は確認用の空リストとして取り込む
- 形式7は3モードを内部保存・書き出しで往復し作者名を保持
- 未知mode・旧フラグ混在は読み込み前に拒否し、保存済み設定を変更しない
- 既存の形式2は明示的なインポートでsevereへ変換し、書き出しは形式7
- 移行画面は社会復帰モードのJSONを読み込み、タグを保持して設定画面を利用可能
- スキ数設定は初期OFF、旧保存は読取だけでOFF。形式7の往復・旧形式1〜6・型検証
