# おしゃべりnote 0.1.6

## 変更点

- お気に入り画面で、選択中のグループの項目を一括削除できます。確認画面にグループの番号・名前・件数が表示されます。
- お気に入り画面の「＃」「＠」から、選択中のグループのタグまたはユーザーIDを共有用にコピーできます。コピーした `[#タグ名]` と `[@ユーザーID]` は「タグ登録支援」に貼り付けて登録できます。
- ユーザーIDで追加した作者は、作者検索の結果から表示名を確認できたときに空欄を補完します。
- 一括登録ダイアログでは、候補が多くても登録先や登録ボタンが一覧の上に残り、候補だけをスクロールできます。
- 「ダッシュボードを無効化する」が有効なとき、noteのアカウントメニューに自分の記事を新着順で検索する「＠表示名」を追加しました。
