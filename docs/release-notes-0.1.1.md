# おしゃべりnote 0.1.1

記事を読み、要約を蓄積し、内容について話すための機能を拡充しました。

## 主な変更

- 「記事全文を取得」で、タイトル・著者・投稿日・URL・本文をクリップボードへコピーできます。
- 本文中のリンク、リンクカード、クリエーターページ、埋め込みの元URL、添付ファイル名・サイズ・URLの取得と整形を改善しました。iframeの強制読み込みやリンク先本文・ファイル本体の取得は行いません。
- 同じ著者の保存済み記事要約を、感想とその続きの会話へ参考情報として添える、暫定的な連作対応を追加しました。要約は著者ID・記事ID別に保存し、再要約で上書きします。連作であると決めつけず、関連する場合だけ参照するよう指示します。
- 記事ページに「前の記事」「次の記事」を追加しました。末尾へスクロールする前でも、noteの読み取り専用APIから公開記事の前後リンクを取得します。
- 要約プロンプトを詳細な内容把握向けに調整しました。感想は600〜1400文字を目安に、具体的な内容を掘り下げ、一般的な称賛や繰り返しによる水増しを避ける指示へ変更しました。
- 記事ページからの要約依頼を受付順のキューで処理します。同じ記事が実行中・待機中なら追加せず、失敗した依頼だけを飛ばし、「中止」では実行中と待機中をすべて取り消します。
- 右隣のおしゃべり画面を読み込み直さず再利用し、必要な場合だけ右隣に新しい画面を開きます。記事タブの表示は維持します。
- 会話タブやお気に入り・設定へ移動しても、実行中の回答の受信・保存と要約キューを継続します。回答は元の会話だけへ保存します。
- 会話タブごとのスクロール位置を復元します。記憶がない場合は最後の発言、記事タブでは最後の依頼文へ合わせます。
- 狭い画面の記事ページでも、noteロゴ横のハンバーガーメニューから記事操作を利用できます。作者検索URLの自動フォーカス指定を削除しました。

## 更新・導入

Chrome・Edge用は `OshaberiNote-0.1.1-chromium.zip`、PC版Firefox 140以上用は `OshaberiNote-0.1.1-firefox.zip` です。同梱の `INSTALL.md` を参照してください。GitHub配布のFirefox ZIPは未署名の一時読み込み用です。Androidは対象外です。

既存の拡張を更新した後は、開いているおしゃべり画面とnoteの記事ページも読み込み直してください。更新前の会話・記事は維持しますが、0.1.0の過去回答から要約Mapを自動生成することはありません。同じ著者の記事を新しく要約してから感想を依頼してください。取得改善を保存済み本文へ適用するには取り込み直してください。

## 検証と制限

- 自動テスト517件成功。Chrome・Firefox向けの両配布物を生成・照合しています。
- 暫定的な連作対応は、同じ著者の他記事の「要約」を参考にする方式です。複数記事本文の一括送信や連作専用タブはありません。AI生成要約の誤りや省略、作品同士の誤った関連付けは起こり得ます。
- 記事タブの「新しい会話」と接続先変更では、記事本文・会話とともに保存済み要約も削除します。保存全体8MiBと送信上限は維持します。
- 生成を続けるには通信を担当するホーム画面を開いておく必要があります。ブラウザタブの終了・再読み込みでは生成が中断され、ブラウザ再起動後の待機分は自動再送しません。
- 自由入力は他の回答の生成中には送信できません。ユーザーチャットを要約キューより優先して予約送信する機能は今回含めません。
- 全埋め込み形式、実保存容量の限界、保存途中のプロセス強制終了からの復旧を網羅した実機検証は行っていません。AI回答の品質や正確性はモデルによって異なります。

Firefox審査用ソースは `OshaberiNote-0.1.1-firefox-source.zip`、配布物のSHA-256は `SHA256SUMS-0.1.1.txt` に記載します。詳細はREADME、PRIVACY.md、docs/manual-test.mdを参照してください。

## 配布ZIPの形式修正（2026-11-09）

Firefoxの審査でZIP内ファイル名のバックスラッシュが拒否されたため、パス区切りをスラッシュへ統一して配布物を差し替えました。アプリ本体29ファイルと0.1.1タグは変更していません。両ブラウザ用ZIP、Firefox審査用ソース内の本体ZIPハッシュ、チェックサム・検証情報を更新しています。以前ダウンロードしたZIPは再取得してください。配布処理の回帰試験を含めて518件成功しました。
