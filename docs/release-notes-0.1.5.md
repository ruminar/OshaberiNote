# おしゃべりnote 0.1.5

## クリエイター能力鑑定

- 専用ホームからnoteの公開プロフィールを取得し、選んだ3〜5本の記事を鑑定できます。破壊力・精密動作性・成長性はOllamaで記事ごとの根拠を抽出し、スピード・射程距離・持続力は取得データから計算します。
- 評価結果と詳細の表示・コピー、結果への質問や指摘ができる「感想戦」、記事評価の指示とOllamaへ送る全文を編集できる「プロンプト設定」を追加しました。送信全文の編集は試験用で、再読み込みや「全文を組み立て直す」で解除できます。
- 記事の取得には右隣の専用タブを使います。取得に失敗した場合は未取得の記事から再開できます。長文の送信用本文を短縮した場合は結果に表示します。文字数とリンクカード数の集計には取得済み全文を使います。
- 公開プロフィール・記事本文・評価資料は、任意でブラウザ内にキャッシュできます。保存済みの資料から再集計でき、作者ごとまたは一括で削除できます。

## お気に入り

- CtrlまたはShiftを押しながら登録すると、お気に入りグループの先頭へ追加します。一括登録でも候補の順番を保ちます。
- noteの左メニューとハンバーガーメニューで、検索やグループ切り替え後にグループごとの一覧位置を復元します。

## 提出ファイル

| 用途 | ファイル |
| --- | --- |
| Chrome・Edge | `OshaberiNote-0.1.5-chromium.zip` |
| PC版Firefox | `OshaberiNote-0.1.5-firefox.zip` |
| Firefox審査用ソース | `OshaberiNote-0.1.5-firefox-source.zip` |
| SHA-256 | `SHA256SUMS-0.1.5.txt` |

鑑定には利用者が設定したOllamaと対応モデルが必要です。お気に入りや通常のnote閲覧はOllama未接続でも使えます。Firefox本体ZIPは未署名の提出・一時読み込み用です。対象はPC版です。

試作版は利用者がChromeとFirefoxでクリエイター能力鑑定を動作確認済みです。
