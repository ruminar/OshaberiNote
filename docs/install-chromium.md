# Chrome / Edge 試作の読み込み

既存のひきこもりnoteを無効にし、拡張管理画面の開発者モードで、このフォルダを「パッケージ化されていない拡張機能」として読み込んでください。

Ollamaを起動し、拡張アイコン →「LLMの設定」→「接続・再試行」→ 接続権限の許可 → モデル選択 →「おしゃべり」→ メッセージ送信の順で確認します。「LLMの設定」で接続先を変更すると会話・モデル選択・システムプロンプトを初期化します。

接続できない場合はOllamaの起動・モデルの登録・接続先URLを確認してください。Ollama側で必要な場合は `OLLAMA_ORIGINS` にこの拡張の実際の `chrome-extension://拡張ID` を追加してOllamaを再起動します。ワイルドカードによる全拡張・全サイトの許可は推奨しません。

クラウドモデルを使う場合はOllama側から外部へ会話が送信されます。完全ローカル運用ではOllama側で `OLLAMA_NO_CLOUD=1` を設定し再起動してください。HTTPのLAN通信は暗号化されません。

この試作は未公開です。拡張OFFは設定画面の「通常のnoteを表示」から行えます。

専用ホームはOS・ブラウザの配色設定に追従します。チャットはCtrl+Enterで送信、Enterで改行します。IME変換中は送信しません。

通常チャット用のシステムプロンプトも「LLMの設定」で保存できます。変更の保存時は通常タブの会話だけを初期化し、空欄で保存すると追加のプロンプトを解除します。

入力は最大200,000文字です。履歴は各会話タブで直近10往復・最大2MiBを保持し、古い分から自動整理するため、履歴量で会話を打ち切りません。長文はOllama側でも切り捨てられる場合があります。

「おしゃべり」上部の「通常の会話」「タグの提案」をタブとして切り替えます。初回は通常タブで、以後は最後に選んだ会話タブとその履歴を開き直し時に復元します。復元だけでは質問を再送しません。各タブの履歴は別々に保存します。タグタブの初回選択時だけ最初の質問を作り、接続・モデル選択済みなら送信します。未接続なら入力欄で待ち、再選択では再送しません。専用プロンプトv1.2と全4グループの最新登録タグ名はタグタブの送信だけに付与します。「新しい会話」は選択中のタブだけ初期化します。提案タグの登録は利用者の操作時だけ行います。
