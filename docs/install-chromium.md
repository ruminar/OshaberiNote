# Chrome / Edge 試作の読み込み

既存のひきこもりnoteを無効にし、拡張管理画面の開発者モードで、このフォルダを「パッケージ化されていない拡張機能」として読み込んでください。

Ollamaを起動し、拡張アイコン →「接続・再試行」→ 接続権限の許可 → モデル選択 → メッセージ送信の順で確認します。設定画面で接続先を変更すると会話は削除されます。

接続できない場合はOllamaの起動・モデルの登録・接続先URLを確認してください。Ollama側で必要な場合は `OLLAMA_ORIGINS` にこの拡張の実際の `chrome-extension://拡張ID` を追加してOllamaを再起動します。ワイルドカードによる全拡張・全サイトの許可は推奨しません。

クラウドモデルを使う場合はOllama側から外部へ会話が送信されます。完全ローカル運用ではOllama側で `OLLAMA_NO_CLOUD=1` を設定し再起動してください。HTTPのLAN通信は暗号化されません。

この試作は未公開です。拡張OFFは設定画面の「通常のnoteを表示」から行えます。
