# おしゃべりnote 0.1.4

タグをまとめて見つけて登録する機能を追加し、検索画面・お気に入りメニューと有料記事判定を改善しました。

## 主な変更

- 専用ホームに「タグ登録支援」を追加しました。提案文から `[#タグ名]` や `#タグ名` を抽出し、選んだ候補だけを指定グループへまとめて登録できます。全ON／OFF、選択件数、追加・登録済み・未登録件数を表示します。
- 現在のお気に入りタグを使う「タグ提案用プロンプトをコピー」と、提案文の「クリア」を追加しました。コピーしたプロンプトは利用者が外部チャットAIへ貼り付けて使います。自動送信はしません。
- 記事メニューの「記事全文を取得」の下に「記事タグを確認」を追加しました。記事に実際に設定されたタグを、本文や募集枠と区別して取得します。
- 完了したAI回答の「コピー」左に「まとめて確認」を追加しました。通常会話・タグ提案などで、押した回答1件だけからタグ候補を取り込めます。貼り付け・記事タグ・AI回答の3入口は共通の選択UIと保存処理を使います。従来のコピー・単体タグ検索／登録は維持します。
- 2段設定の単体タグ登録ダイアログを2列×4行にしました。共通の一括登録も通常4／2段8グループに対応し、非表示グループのデータは維持します。
- タグ画面・単一語検索に、選択中グループへ追加する「＃」をTLリンクの左に表示します。複数語・作者指定・引用符付き検索等は対象外です。SPAで検索語を変えた場合も登録対象を更新します。
- 共通左メニューとハンバーガーでは、お気に入り項目一覧だけをスクロールし、グループ切り替えやTLなどを上に残します。
- 検索の「関連する話題」を初期非表示にし、「新着」隣の「関連」で開閉できるようにしました。
- 「有料記事を非表示」がONの検索画面で、メンバーシップタブと「すべての記事／有料の記事」の絞り込み欄を隠します。既に開いた有料検索URLの条件や検索結果の読み込み処理は変更しません。
- 有料記事の作者アラートで、「記事」ラベルや罫線のない単品購入欄にも対応しました。同じ表示中の購入欄に購入ボタンと正の価格がある場合を検出します。
- 配布生成時にmanifestと画面の版番号・ランタイムファイルを検証します。版番号が不一致の場合は既存の出力を消す前に停止します。

## 更新と提出ファイル

- Chrome・Edge：`OshaberiNote-0.1.4-chromium.zip`
- PC版Firefox 140以上：`OshaberiNote-0.1.4-firefox.zip`
- Firefox審査用ソース：`OshaberiNote-0.1.4-firefox-source.zip`
- SHA-256：`SHA256SUMS-0.1.4.txt`

更新後は専用ホームとnoteページを再読み込みしてください。既存の設定・お気に入り・会話・記事は維持します。新しい設定キー・権限・保存形式は追加していません。一括登録の保存先はおしゃべりnote自身で、ひきこもりnoteとの自動共有はしません。移行には既存の設定JSONを使用します。

Firefox本体ZIPは未署名の提出／一時読み込み用です。Androidは対象外です。ストアへの反映は利用者が行います。

## 検証と制限

- 構文検証・全661件の自動試験成功。両ブラウザの配布物・リリース対象ソース・Firefox提出用ソースからの再ビルドを照合します。
- ローカルChromeの匿名DOMで、＃配置・一括登録・関連開閉・一覧スクロール・検索絞り込みの非表示と復元を確認しました。実note上の全画面やFirefox／Edgeの実操作を網羅するものではありません。
- noteのDOM構造やモデルによるAI回答の差異は残ります。既存の実機確認事項はdocs/manual-test.mdを参照してください。
