# おしゃべりnote 0.1.3

お気に入りの整理操作を改善し、note公式DOMの変更へ対応しました。

## 主な変更

- お気に入りの整理画面に共通の「移動先」を追加しました。一度宛先を選べば、各行の「移動」で続けて仕分けできます。宛先は一覧の外に置き、移動後も宛先とスクロール位置を保持します。手入力のタグ追加欄は撤去し、登録はnoteの各ページやAIのタグ提案から行います。
- 設定画面と共通左メニューで、別のグループ番号へのドラッグ移動、現在の番号へのドロップによるお気に入り削除に対応しました。ドラッグ中は現在番号を赤いゴミ箱で示します。記事や作者などの本体を削除する操作ではありません。
- 共通左メニュー内の項目間・末尾へのドロップで並べ替えできます。通常のリンクと番号クリック、設定画面の上下・削除・移動ボタンは維持します。
- 作者検索（from:@ユーザーID）から、選択中グループへ作者を直接登録する「＠」ボタンを追加しました。同じグループに登録済みの場合は表示しません。
- ユーザーメニューのポイント残高・チャージ枠を「有料記事を非表示」に、プレミアムサービスとnote活用術の入口を「おすすめ非表示」に連動させました。ヘルプ・履歴・ログアウトなどは維持します。
- note活用術の/help・/help/pg/配下にも、4／8グループの左メニューと狭幅メニューを適用しました。
- タグ一覧の新カード構造での有料記事非表示、記事末尾の新しいチップ枠の構造に対応しました。
- 記事お気に入りフォームのラベル・状態文・操作部の文字色指定を補強しました。

## 更新と提出ファイル

- Chrome・Edge：`OshaberiNote-0.1.3-chromium.zip`
- PC版Firefox 140以上：`OshaberiNote-0.1.3-firefox.zip`
- Firefox審査用ソース：`OshaberiNote-0.1.3-firefox-source.zip`
- SHA-256：`SHA256SUMS-0.1.3.txt`

更新後は、おしゃべり画面とnoteページも再読み込みしてください。保存済み設定・お気に入り・会話は維持します。保存形式・権限は追加していません。Firefox本体ZIPは未署名の提出／一時読み込み用です。Androidは対象外です。

## 検証・制限

- 自動テスト623件成功。両ブラウザの配布物とタグ対象ソース、Firefox審査用ソースからの再ビルドを照合します。
- 利用者が実環境で動作確認し、0.1.3の採用を確認済みです。ローカルChromeの匿名DOMでも基本表示・保存・ドラッグイベント処理を確認しています。全ブラウザ・全画面の実機操作を網羅した検証ではありません。
- タッチドラッグは保証せず、設定画面の操作ボタンを維持します。Shiftキーによる登録・一括移動は今回含めません。
- ドラッグによる移動・削除も設定へ保存されます。必要に応じて操作前に設定JSONを書き出してください。

ストアへの反映は利用者が行います。詳細はREADME、PRIVACY.md、docs/manual-test.mdを参照してください。
