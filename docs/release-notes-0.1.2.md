# おしゃべりnote 0.1.2

お気に入りとnote上の導線を拡充し、記事の登録や8グループ表示に対応しました。

## 主な変更

- お気に入りに記事を登録できます。記事ページの「&」から登録先を選び、専用ホームで整理・移動・削除できます。登録する情報は記事ID・タイトル・URLで、本文取得やLLM送信は開始しません。
- 「お気に入りグループの表示」を追加しました。初期値は従来の4グループで、「2段（8グループ）」を選ぶと左サイドバーは4個×2行、ハンバーガー内は8個×1行になります。通常表示に戻しても⑤〜⑧は保持し、選択中だった場合は①へ戻ります。
- 登録・編集・移動先は表示中のグループに限定し、別画面に残った非表示グループへの操作も拒否します。設定JSONも8グループに対応し、旧4グループJSONの読み込みで既存の後半グループを消しません。ひきこもりnote形式9の読み込みに対応しました。
- 未ログインと公式ヘッダから確認できた場合、追加した「フォロー中のTL」は新着検索画面を開きます。ログイン済み・判定不能では従来どおりです。
- フォロー中TLの公式カテゴリナビを非表示にし、急上昇などへの導線を抑えます。拡張のメニューや記事一覧は維持します。
- 歯車の遷移先を、クリエイターページでは「ユーザーの表示管理」、公開記事やお気に入りメニューを使う画面では「お気に入り」に調整しました。
- 有料記事非表示の対象に「¥0〜」かつ「割引あり」の条件付き無料記事を追加しました。通常の0円表示、表示許可作者、購入済み一覧は従来どおりです。
- 通知の作者アイコンに「　表示名（@ユーザーID）」の標準ツールチップを追加しました。非表示設定作者は名前の前に「！」を付け、遅延挿入と設定変更に追従し、OFFで元のtitleへ戻します。
- タグ提案プロンプトを登録済みタグとの関連性を優先する内容へ調整しました。保存済み全グループのタグだけを参考データとして送信します。
- 設定の選択欄の見た目を統一し、Chromeで記事登録先の選択肢が読みにくくなる配色を修正しました。画面内の版表示も0.1.2へ揃えました。

## 更新・提出用ファイル

- Chrome・Edge：`OshaberiNote-0.1.2-chromium.zip`
- PC版Firefox 140以上：`OshaberiNote-0.1.2-firefox.zip`
- Firefox審査用ソース：`OshaberiNote-0.1.2-firefox-source.zip`
- SHA-256：`SHA256SUMS-0.1.2.txt`

更新後は開いているおしゃべり画面とnoteページも再読み込みしてください。設定・お気に入り・会話は維持します。8グループを使った後に旧版へ戻す場合、旧版では後半グループを扱えないため、事前に設定JSONを書き出してください。製品間の完全な8グループ往復には受取側の対応版が必要です。

Firefox ZIPは未署名の提出／一時読み込み用です。ストアへの反映・署名は別途行います。Androidは対象外です。
