2026-11-05の自動確認：372件成功（失敗・スキップなし）。一時プロファイルのEdge 156.0.4314.58とChrome 156.0.8078.80では、実際の拡張読込、おしゃべり初期表示、設定への切替、接続先変更での初期化を確認しました。実行時例外は0件でした。Firefoxは生成Manifest・Event Pageの自動試験までで、実ブラウザ確認は未実施です。

Chromium・FirefoxのZIPは各25ファイルで、配布フォルダ・実行用ソースとのバイト一致を検証しています。SHA-256は生成物 `dist/verification.json` に記録します。

- 初回表示で勝手に接続せず、接続ボタンから権限を要求する。拒否してもnote閲覧とお気に入りが使える。
- ローカルOllamaに接続し、モデル選択・複数行入力・逐次応答・中止が動く。
- 中断した会話が次回送信に含まれず、再読み込みで生成が勝手に再開しない。
- 「新しい会話」で生成・入力・保存履歴が消え、再読み込みや別タブからも復活しない。
- 接続先を変更すると会話・入力・モデル選択を消し、以前の会話を新しい接続先へ送らない。取消時は保持する。
- 生成中に設定・お気に入りへ移動、モデル変更、OFF、ページ再読み込みを行うと中断する。
- 別タブとの二重生成を拒否し、片方の新しい会話・接続先変更・OFFを他方にも反映する。
- 権限取消・サーバー停止・通信途中の切断・保存上限で停止し、自動再送しない。
- モデルをOllama側で削除して再接続すると、選択し直せる。モデルを勝手にダウンロードしない。
- LAN内の別PCを手動設定して接続できる。HTTPの非暗号化を確認する。
- ひきこもりnoteのJSONを読み込み、未対応項目を破棄し、省略項目と `false`・空値を区別する。不正値では設定全体を保持する。
- 自製JSONを往復し、会話と権限付与状態を含めない。読込のみで接続しない。
- note公式ホーム、拡張アイコンはおしゃべりを開き、note上の歯車は設定を開く。OFF時は通常ホームへ戻る。
- お気に入り4グループ、タグ・作者・マガジン・メンバーシップ登録、作者表示管理、検索の新着固定、表示制御を確認する。
